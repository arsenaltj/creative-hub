# 测试记录与交付边界

版本：GamePerf Studio 0.2.0；数据契约 schema 1。此记录是开发环境中的实际验证，不是生产认证，也不是对目标服务器已部署的声明。

## 已通过：后端接口与数据流程

命令：`python -m pytest tests -q`

最终结果：**15 passed in 20.69s**。测试使用临时 SQLite 数据库、真实应用路由及 FastAPI TestClient，不使用生产账号或业务数据。

| 范围 | 验证内容 |
| --- | --- |
| 登录与访问 | 未登录访问拒绝、登录会话、写入 CSRF、跨来源限制、安全响应头 |
| 登录失败保护 | 连续失败的次数限制 |
| 记录操作 | 新建、更新、删除、引用关系及 If-Match 版本冲突 |
| 角色限制 | viewer 不可写、reviewer 不可改候选证据 |
| 独立审核 | 提交者不能自审；冻结候选不可继续编辑；不同审核者记录决定 |
| 候选完整性 | 提交所需字段；示例记录不能被当作真实候选提交 |
| 能力层级 | 父子节点不能形成循环 |
| 反馈转任务 | 一次性转换，重复请求不生成重复任务 |
| Agent 回传 | 只写范围、事件幂等、不同内容冲突、令牌撤销 |
| 导入 | 只创建业务副本、不带入审核结论、不覆盖已有同 ID 蓝图节点 |
| 持久化 | 数据库重新初始化不会清空现有记录 |
| 输入边界 | 无效类型、超长请求拒绝 |
| 修改参与者 | 不只是创建者，所有修改参与者也不能审核相同候选 |
| 并发转换 | 同一个反馈同时转换时，仍只产生一个关联任务 |
| 备份恢复 | 在线 SQLite 备份、离线恢复、恢复后清除会话与集成令牌 |

审核当前是人工填写的独立核验记录，不是自动性能判定；这些测试不能证明审核人实际检查了设备证据。

## 已通过：前端渲染与交互

命令：`python scripts/check_ui.py`，可通过 `GP_QA_OUT` 指定输出目录，`GP_CHROMIUM` 指定 Chromium 可执行文件；可选依赖见 `requirements-ui.txt`。

已检查：1600 像素桌面总图；节点编辑与子能力新增；任务关联实验、提交冻结及本机审核演示；反馈转任务；九个页面无 JavaScript 异常；390 像素手机导航与页面宽度。截图来自实际 HTML/CSS/JS 渲染，不是概念生成图。

**重要限制：** 本次浏览器环境的管理策略阻止了 `file://` 和 localhost 的导航，因此使用 Playwright `set_content` 渲染本地源码，并为 localStorage 显式提供内存测试适配器，没有绕过浏览器策略。已验证编辑会写入该适配器，**没有在此浏览器中验证真实文件打开、跨刷新持久化或浏览器到服务器的完整登录链路**。后端登录与 SQLite 持久化由上述接口测试独立覆盖。目标服务器上仍须进行真实浏览器端到端验收。

本机体验版的审核无真实身份隔离，不构成独立验收。服务器版通过账号与贡献者记录实施应用层限制。

## 已通过：静态检查

- `node --check web/app.js`：JavaScript 语法通过。
- `python -m compileall`：应用、管理脚本、示例与测试语法通过。
- `bash -n scripts/*.sh`：逐个 shell 脚本语法通过。
- 两份 Compose 文件通过 YAML 解析；这不等同于 `docker compose config` 或实际运行验证。

## 尚未验证 / 尚未实现

本环境没有 Docker，尚未构建镜像或启动 Compose。锁定依赖取自本次已安装并用于测试的环境；目标机器的首次下载、平台兼容性和容器运行仍需确认。尚未验证用户服务器的 DNS、TLS、端口、反向代理、磁盘权限和备份策略。

未连接真实调参 Agent、真机、构建链或媒体/用户反馈系统；未执行性能实验、刷机、代码修改、自动评价或发布。接口只接收记录，链接不会自动抓取。

未完成高并发、长期稳定性、完整渗透、供应链扫描、企业 SSO、项目级数据隔离或不可篡改审计。部署真实业务前需要环境授权与相应评审。

## 目标环境必须补做的验收

使用实际域名登录；验证角色和审核权限；创建记录后刷新、重登、重启仍可读；确认浏览器故障明确报错而非退回本机数据；检查 HTTPS 和安全 Cookie；执行一次测试备份恢复；最后用一条获准的脱敏 Agent 回传验证接口。详见 `DEPLOYMENT.md`。
