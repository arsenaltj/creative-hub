# Changelog

## 0.2.0 — 2026-09-19

将 v0.1 设计蓝图转为可编辑的网页记录工作台。

新增节点与子能力维护、任务看板、关联实验与方法候选、反馈转任务、JSON 数据交换；提供单文件体验版和独立服务器版本。

服务器版提供登录、四种角色、服务端会话、CSRF、同源限制、记录版本冲突检查、已提交候选冻结、参与者禁止自审、审计记录和幂等写入型 Agent 回传接口。

提供 Docker / 可选 Caddy 入口、现有 Nginx 适配片段、只读环境检查、数据库在线备份及显式离线恢复。恢复清除会话和集成令牌，防止旧凭证复活。

不包含 Agent 运行时、真实设备执行器或自动评测。部署包未在用户服务器上线，目标环境需另行验收。
