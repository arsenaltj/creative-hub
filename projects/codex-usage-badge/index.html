来源、修改与使用说明 ↗
它会读取什么？

读取 Codex 配额、本机会话 ID 与累计 Token，并扫描本地项目大小；颜色保存在本机。公开包不含实际账号、聊天数据库或日志。配额查询仍使用 Codex 官方服务。

本地连接有什么风险？

插件通过 127.0.0.1:39222 调试接口加载界面。接口只监听本机，但本机其他程序可能通过它操作 Codex。SHA-256 可核对文件完整性，不能代替数字签名。

怎么卸载或更新？

运行 %LOCALAPPDATA%\CreativeHub\CodexUsageBadge\Uninstall.cmd，正常重启 Codex 关闭调试连接。插件目录保留为可恢复备份。更新时下载新 Hub 维护版重新安装。

已有试用版或 macOS 怎么办？

请先停止其他 Badge 版本再使用，它们共享调试端口。Hub 不覆盖现有试用版；目前仅提供 Windows 安装器。macOS 请参考原项目说明。
