# VibeDock

圆屏四区中央打开工具选择页，在第二页选定 Codex 或 WorkBuddy 才会切换；每个工具保留自己的四个任务槽位。本站仅使用模拟数据。

👉 [在线演示](https://arsenaltj.github.io/creative-hub/projects/vibedock/)

Public interactive demo with simulated data only. No real client connections, recording or command execution.

👉 [下载 Windows PC 预览版](https://github.com/arsenaltj/creative-hub/releases/tag/vibedock-v0.4.0) · [PC 端源码](./companion/README.md)

PC 预览版可读取部分本机真实任务状态和 Codex 最新回复节选。它仍使用浏览器圆屏模拟器；物理固件、蓝牙数据、真实审批和原生语音尚未接通。下载包为免安装 ZIP，自带 Node.js，解压后双击 `Start-VibeDock.cmd`。
