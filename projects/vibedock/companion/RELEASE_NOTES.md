# VibeDock PC 0.4.0 · Windows 免安装预览版

下载 `VibeDock-Windows-Portable-0.4.0.zip`，解压后双击 `Start-VibeDock.cmd`。软件会在本机启动工作台并打开浏览器；关闭启动窗口即停止服务。ZIP 已包含 Node.js 运行时，无需额外安装。

本版可查看本机 Codex 任务状态、部分最新回复与已知用量，以及 WorkBuddy 本地任务状态；新增首次使用连接检查、未上屏任务显式换槽、圆屏输出节选和四区偏好保存。源码位于 `projects/vibedock/companion/`。

这是 PC 端预览版。圆屏为浏览器模拟器；物理吧唧固件与蓝牙数据通道尚未接入。真实审批、原生语音触发以及 WorkBuddy 会话正文未接通，界面会明确提示。Windows 安装包、托盘和自动启动也尚未提供。
