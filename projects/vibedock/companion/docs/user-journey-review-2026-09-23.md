# VibeDock 用户旅程与下一步

| 用户步骤 | 当前体验与问题 | 本轮调整 / 后续动作 |
|---|---|---|
| 启动与连接 | 0.4 Windows 免安装预览包自带运行时，但仍需保留启动窗口；模拟圆屏与真机体验不同 | 后续做 Windows 托盘和自动重连，再接 BLE 设备与固件。首次引导已经分别显示 PC、工具、真机连接状态。 |
| 抬眼看四区 | 颜色、图标和文字能区分状态；固定四区不会自动显示新任务 | 0.4 在 PC 和模拟圆屏提示最近未上屏任务，并由用户明确指定替换哪个分区；真机尚未验收。 |
| 切工具 | 中央原先一触即切，容易误触 | **已改**：中央打开触控菜单，再进入工具选择页；选目标工具后才切换。当前工具、待查看数和目标连接状态可见，返回不切换。 |
| 找需要介入的任务 | WorkBuddy `pending` 可能是尚未开始，原提醒容易误导 | **已改**：这类状态显示“等待 / 待核对”，不计入需要处理提醒。Codex 审批信号覆盖和 WorkBuddy 新任务实时变化仍需真客户端验收。 |
| 查看并回应 | 0.4 模拟圆屏可分页读最新回复节选，但长命令和 diff 仍须在 PC 看；真实批准/拒绝未接通 | 模拟确认页增加任务名；真实审批只在能核对任务、请求和影响范围时开放，否则在 PC 原客户端处理。 |
| 语音与用量 | 原生语音入口尚未接通；WorkBuddy Token 暂不可用 | 已修复语音页标题被压缩遮挡。后续先验证精确定位原客户端任务，再触发其语音入口；额度与历史 Token 继续分开显示。 |

当前公开站仅演示交互。硬件固件、BLE 通信、真实审批和语音不属于已完成能力。
