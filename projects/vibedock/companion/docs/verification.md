# 0.1 验证记录

2026-09-18，Windows，本机 Node.js v24.15.0。

## 自动化

`npm test`：17 项通过（Node 内置测试）。

- 审批只在回执后改变状态，槽位固定；同动作重传不重复执行。
- 不同动作并发处理同一审批被拒绝；拒绝只暂停该任务。
- 过期上下文、请求版本、工具不匹配与复用动作编号被拒绝。
- 设备离线禁止设备动作；PC 可继续改变状态，重连得到最新状态。
- 重置期间在途审批不修改替换后的新请求。
- 真实刷新晚于模式切换返回时，不覆盖模拟数据。
- 未知 Token 不当作 0；额度从 usedPercent 正确换算。
- 历史完成不冒充原客户端实时完成；WorkBuddy pending 不冒充可批准请求。
- WorkBuddy 请求使用固定官方域名与鉴权头；结果不包含令牌；授权失败有明确错误。
- HTTP 操作、SSE 初始与后续快照；跨站、错误 Host、缺少会话与错误格式校验。
