INTEGRATIONS
连接你的工具
默认跟踪本机 Codex 和 WorkBuddy，无需云端令牌。当前采用只读兼容接入，客户端更新后可能需要适配。
Codex
官方 App Server 提供任务列表与额度，本地事件提供开始、完成、中断状态，每 2 秒读取。长时间没有新事件时显示未知。可通过 PermissionRequest 钩子接收审批提示；请在 Codex 设置 → Hooks 中审阅 VibeDock 钩子。
WorkBuddy 本机桌面
只读跟踪本地状态库和客户端心跳。pending 可能是等待输入或尚未开始，不直接当成可批准请求。
仅需要查看云端任务时填写。连接后切换为云端列表；可用上方按钮返回本机桌面。不会读取客户端私有凭据。
原生语音与审批
已接入 Windows 任务链接打开请求；实际页面需在原客户端核对。语音触发和直接审批尚未接入。状态读取不会获得审批权限；模拟模式可体验动作回执。本程序没有录音、识别或转写模块。
